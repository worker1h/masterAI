# 阶段一实验记录

## 数据锁定

- 数据集：ImpactMesh-Flood v1，Hugging Face 当前主分支。
- 本轮落盘：validation 的 S1RTC、DEM、MASK，共 2,171 个对齐样本。
- S1RTC：四时相 × VV/VH × 256 × 256；时相顺序为 pre-month、pre-event、event、post-event。
- DEM/MASK：单波段 256 × 256 GeoTIFF；抽查样本与 MASK 的 CRS、仿射变换一致。
- MASK 编码已通过空间形态和四时相散射统计核验：0 为背景、1 为永久水体、2 为新增洪水。正式实验仅以类别 2 为正类。

## 已完成模型

标准三层 U-Net，BCEWithLogits + Dice Loss，AdamW。配置覆盖 E0（event SAR）、E1（event SAR + DEM）、E2（pre-event + event SAR）、E3（pre-event + event SAR + DEM）。训练过程保存最佳 checkpoint、逐 epoch 指标与运行元数据。

## 初始 E0 smoke run（已作废）

- 环境：现有 Conda `daily`，CUDA 可用，RTX 5070 12 GB。
- 配置：固定种子 42；16 个 validation 图块中 12/4 随机拆分；3 epochs；base channels=16。
- 初始实现错误地把 MASK > 0 合并为正类，因此 IoU 0.7521 等数值全部作废，仅保留为数据语义排查记录。

修正标签后已完成事件级留出的 E0-E3 实验，详见《第一阶段实验报告》。当前最优 E2 的 IoU 为 0.4940、Dice/F1 为 0.6613。
