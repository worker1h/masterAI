# 洪析先知第一阶段实验报告

## 1. 结论摘要

已完成 ImpactMesh-Flood v1 全量必要模态的数据核验、U-Net 基线与 E0-E3 消融。正式实验使用官方 train 19,448 图块训练、val 2,171 图块选模，并在 12 个完全未见事件组成的 test_holdout 562 图块上评估泛化。当前最优方案为 E2（pre-event SAR + event SAR），val IoU 0.5691、test_holdout IoU 0.4941。多时相信息带来明确增益；DEM 在 event-only 上小幅增益，但在多时相基础上未进一步提高峰值。

时相与标签统计表明 MASK 类别 2 对应 event 时刻新增洪水：该类像素 VV/VH 均值从 pre-event 的 -9.964/-15.263 dB 降到 event 的 -15.179/-21.171 dB，post-event 回升至 -10.785/-16.161 dB。由此选择路线 B：现阶段作品定位为“多时相 SAR 洪涝智能评估”，不将 event 状态识别表述成未来预测。

## 2. 数据与标签

- 数据版本：ImpactMesh-Flood v1。
- 本轮数据：validation 的 S1RTC、DEM、MASK，各 2,171 个图块。
- S1RTC：4 时相（pre-month、pre-event、event、post-event）× 2 极化（VV/VH）× 256 × 256。
- DEM/MASK：单波段 256 × 256 GeoTIFF；抽查 CRS、分辨率和仿射变换一致。
- MASK 编码：0 背景、1 永久水体、2 新增洪水。模型只将类别 2 作为正类，类别 1 为负类。
- 归一化：S1RTC 使用官方统计量 VV -9.98±4.24 dB、VH -15.968±4.105 dB；DEM 使用 141.786±189.363。

## 3. 实验设计

统一使用三层 U-Net、BCE + Dice Loss、AdamW、固定种子 42、12 epochs、base channels 16、正类权重 4.0和混合精度。所有实验使用官方 train/val、相同网络容量和训练预算；test_holdout 只在模型选择完成后评估。

| 实验 | 输入 | Val IoU | Val Dice | Holdout IoU | Holdout Dice | Holdout P/R |
|---|---|---:|---:|---:|---:|---:|
| E0 | event VV/VH | 0.4774 | 0.6463 | 0.3616 | 0.5312 | 0.4036 / 0.7767 |
| E1 | event VV/VH + DEM | 0.5066 | 0.6725 | 0.3803 | 0.5510 | 0.4404 / 0.7358 |
| E2 | pre-event VV/VH + event VV/VH | **0.5691** | **0.7254** | **0.4941** | **0.6614** | **0.5865 / 0.7583** |
| E3 | pre-event VV/VH + event VV/VH + DEM | 0.5614 | 0.7191 | 0.4697 | 0.6392 | 0.5236 / **0.8203** |

test_holdout 的 12 个事件中有 1 个事件（EMSR766）不含任何洪水正类像素。排除该空事件后，以事件等权计算的宏平均 IoU 为 E0 0.2952、E1 0.2915、E2 0.3251、E3 0.3199；E2 仍为最优。总体像素级指标与正洪水事件宏平均需同时报告，避免大型事件主导结论或空事件扭曲均值。

## 4. 消融结论

在 test_holdout 上，E2 相对 E0 的 IoU 提高 0.1324，Dice 提高 0.1302，证明灾前参照能显著减少单时相 SAR 对永久水体和其他低散射区域的混淆。E1 相对 E0 小幅提高 0.0186 IoU，表明完整数据下 DEM 对单时相有有限帮助；E3 低于 E2，说明简单通道拼接未能在多时相基础上继续增益。E3 的 Recall 最高但 Precision 较低，呈现“减少漏报、增加误报”的权衡。

## 5. 事件级严重度

按事件聚合 `新增洪水像素 / 排除永久水体后的有效陆地像素`。阈值只由训练事件的三分位数产生：一般/严重边界 0.01473，严重/非常严重边界 0.08905；留出事件固定复用，不重新计算。

## 6. 局限与后续正式实验

2026-08-13 已完成类别不平衡与边界专项实验。训练集洪水像素占比为 8.50%；对洪水图块再次过采样并叠加 Focal/Tversky 会造成重复正类补偿，holdout IoU 降至 0.4387。保留原始图块分布、将 `pos_weight` 从 4 降至 2，并增加五像素边界带权重后，holdout IoU/Dice/Precision/Boundary F1 分别达到 0.4981/0.6650/0.5955/0.5420，略高于原 E2 的 0.4941/0.6614/0.5865/0.5329。详见 `docs/类别不平衡与边界实验报告.md`。

正式单随机种子实验已完成，但竞赛最终统计仍需至少三个随机种子并报告均值和标准差。DEM 路线需尝试地形独立编码器、坡度/相对高程派生量或门控融合；若重复实验仍不能超过 E2，则把地形先验从核心创新降级为辅助召回策略。还需在 val 上选择概率阈值并固定到 test_holdout，而非长期默认 0.5。
