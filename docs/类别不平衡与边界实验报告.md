# 类别不平衡与边界实验报告

日期：2026-08-13  
环境：既有 conda `daily` 环境  
基线：E2（pre-event + event SAR）

## 1. 数据诊断

训练集共 19,448 个图块，其中 12,447 个含新增洪水，含洪水图块占 64.0%；但新增洪水像素仅占全部像素的 8.50%。按洪水面积比例分档：无洪水 7,001 个、0～1% 3,827 个、1%～10% 4,487 个、10%以上 4,133 个。因此主要问题是像素级不平衡，而不是单纯缺少正样本图块。

## 2. 实现内容

- 新增按洪水占比分档的 `WeightedRandomSampler`，可配置四档目标概率，并缓存掩膜统计。
- 新增 Focal BCE、Tversky Loss，以及兼容原基线的统一 `segmentation_loss`。
- 新增由形态学膨胀与腐蚀构造的双侧边界带，只提高真实边界邻域的 BCE 权重。
- 新增容差 2 像素的 Boundary Precision、Boundary Recall 和 Boundary F1。
- 原 E2 配置及权重不变，新实验输出到独立目录。

## 3. 正式对照结果

| 方案 | Val IoU | Holdout IoU | Holdout P/R | Boundary F1 | 正洪水事件宏 IoU |
|---|---:|---:|---:|---:|---:|
| 原 E2 | 0.5691 | 0.4941 | 0.5865 / 0.7583 | 0.5329 | 0.3251 |
| 重采样 + Focal/Tversky + 边界 | 0.5238 | 0.4387 | 0.4753 / 0.8506 | 0.4545 | 0.3116 |
| **降低正类权重 + 边界带** | **0.5757** | **0.4981** | **0.5955 / 0.7528** | **0.5420** | **0.3334** |

第一组失败说明原基线的 `pos_weight=4` 已经提供了明显的正类补偿；再对含洪水图块过采样并使用偏召回的区域损失，会重复放大正类，使预测范围过大。其空洪水事件误报像素达到 7,392，故不采用。

第二组保留原始图块分布，把 `pos_weight` 降至 2，并使用 5 像素边界带权重。相较原 E2，未见事件 IoU 提升 0.0040，Precision 提升 0.0090，Boundary F1 提升 0.0091，正洪水事件宏 IoU 提升 0.0083，说明总体误报与边缘定位得到小幅改善。

## 4. 限制与结论

唯一无洪水事件的预测正像素由 1,599 增至 2,155，说明新方案并未改善所有空场景。当前将 `formal_e2_boundary_precision` 作为类别不平衡与边界处理的改进候选，但仍需至少三个随机种子复验，并在 validation 上独立校准阈值后才能替换竞赛主模型。

完整数值见 `outputs/imbalance_boundary_summary.csv`；权重与逐事件结果见 `outputs/formal_e2_boundary_precision/`。
